# T0863: User Execution

- Catalog: [T0863](https://attack.mitre.org/techniques/T0863)
- Kind: technique · ATT&CK 19.2
- Domains: ics-attack
- Version: 1.1

## Technique

Adversaries may rely on a targeted organizations user interaction for the execution of malicious code. User interaction may consist of installing applications, opening email attachments, or granting higher permissions to documents. 

Adversaries may embed malicious code or visual basic code into files such as Microsoft Word and Excel documents or software installers. (Citation: Booz Allen Hamilton) Execution of this code requires that the user enable scripting or write access within the document. Embedded code may not always be noticeable to the user especially in cases of trojanized software. (Citation: Daavid Hentunen, Antti Tikkanen June 2014) 

A Chinese spearphishing campaign running from December 9, 2011 through February 29, 2012 delivered malware through spearphishing attachments which required user action to achieve execution. (Citation: CISA AA21-201A Pipeline Intrusion July 2021)

## Procedure

1. **Applicability gate.** If none of the platforms/domains exist in scope, record `T0863 N/A: <reason>` and stop.
2. **Instance inventory.** Hosts, identities, SaaS apps, ICS nodes, mobile devices. One workstation is not an inventory.
3. **Oracle.** Define pass/fail: procedure succeeded (control bypassed / action completed) vs blocked vs detected.
4. **Execute / emulate.** Follow the technique description as the minimum procedure set. Persist command output, proxy logs, or pcap under `/tmp` or the engagement dir and **re-read** it.
5. **Sub-techniques.** If this ID has children, open each child file and run it. Parent-only testing is incomplete when sub-techniques exist.
6. **Detection check.** Using the same evidence, ask whether the listed data sources would have fired. Missing telemetry is a finding (visibility gap), not a skip.
7. **Mitigation negation.** For each mitigation below, retry with the control on and bypassed. Unchanged oracle = control failed.
8. **CAPEC / CWE close-out.** Run each mapped CAPEC file in the `capec` skill, then related CWE files in `cwe`. ATT&CK without CWE is a procedure note, not a weakness finding.
9. **Report.** Cite `T0863`, tactic, CAPEC/CWE IDs, instance, oracle, evidence path.
