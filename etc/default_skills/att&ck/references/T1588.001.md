# T1588.001: Malware

- Catalog: [T1588.001](https://attack.mitre.org/techniques/T1588/001)
- Kind: sub-technique · ATT&CK 19.2
- Domains: enterprise-attack
- Version: 1.1

## Technique

Adversaries may buy, steal, or download malware that can be used during targeting. Malicious software can include payloads, droppers, post-compromise tools, backdoors, packers, and C2 protocols. Adversaries may acquire malware to support their operations, obtaining a means for maintaining control of remote machines, evading defenses, and executing post-compromise behaviors.

In addition to downloading free malware from the internet, adversaries may purchase these capabilities from third-party entities. Third-party entities can include technology companies that specialize in malware development, criminal marketplaces (including Malware-as-a-Service, or MaaS), or from individuals. In addition to purchasing malware, adversaries may steal and repurpose malware from third-party entities (including other adversaries).

## Exhaustive test law

This is an ATT&CK sub-technique. Inventory every asset/account/network path where the procedure can run on the listed platforms. Execute (or purple-team simulate) **every** procedure variant in the description — not one benign example. Complete means: each in-scope instance was exercised or ruled out with saved evidence, detections were checked against the same evidence, mitigations were bypass-tested, and mapped CAPEC/CWE procedures were run.

A detection rule without an execution attempt is not a T1588.001 test.

## Procedure

1. **Applicability gate.** If none of the platforms/domains exist in scope, record `T1588.001 N/A: <reason>` and stop.
2. **Instance inventory.** Hosts, identities, SaaS apps, ICS nodes, mobile devices. One workstation is not an inventory.
3. **Oracle.** Define pass/fail: procedure succeeded (control bypassed / action completed) vs blocked vs detected.
4. **Execute / emulate.** Follow the technique description as the minimum procedure set. Persist command output, proxy logs, or pcap under `/tmp` or the engagement dir and **re-read** it.
5. **Sub-techniques.** If this ID has children, open each child file and run it. Parent-only testing is incomplete when sub-techniques exist.
6. **Detection check.** Using the same evidence, ask whether the listed data sources would have fired. Missing telemetry is a finding (visibility gap), not a skip.
7. **Mitigation negation.** For each mitigation below, retry with the control on and bypassed. Unchanged oracle = control failed.
8. **CAPEC / CWE close-out.** Run each mapped CAPEC file in the `capec` skill, then related CWE files in `cwe`. ATT&CK without CWE is a procedure note, not a weakness finding.
9. **Report.** Cite `T1588.001`, tactic, CAPEC/CWE IDs, instance, oracle, evidence path.
