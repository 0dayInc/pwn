# CWE-550: Server-generated Error Message Containing Sensitive Information

- Catalog: [CWE-550](https://cwe.mitre.org/data/definitions/550.html)
- Abstraction: Variant · Structure: Simple · Status: Incomplete
- Likelihood of exploit: not stated
- CWE list: 4.20

## Weakness

Certain conditions, such as network failure, will cause a server error message to be displayed.

## Extended description

While error messages in and of themselves are not dangerous, per se, it is what an attacker can glean from them that might cause eventual problems.
