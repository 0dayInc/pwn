# CWE-382: J2EE Bad Practices: Use of System.exit()

- Catalog: [CWE-382](https://cwe.mitre.org/data/definitions/382.html)
- Abstraction: Variant · Structure: Simple · Status: Draft
- Likelihood of exploit: not stated
- CWE list: 4.20

## Weakness

A J2EE application uses System.exit(), which also shuts down its container.

## Extended description

It is never a good idea for a web application to attempt to shut down the application container. Access to a function that can shut down the application is an avenue for Denial of Service (DoS) attacks.

8. **Report.** Every finding cites `CWE-382`, instance, oracle, evidence path, and residual risk. A narrative without an artifact is not a test.
